# 3D Character Model Instructions

To display your custom 3D Anime Character:

1. Download or export your 3D model in **.glb** format (binary glTF).
   - Recommended free sources: Sketchfab (filter by downloadable .glb), Ready Player Me, Mixamo, or CGTrader.
2. Rename the model file to:
   `character.glb`
3. Place it inside this exact folder:
   `D:\portfolio-3d\assets\models\character.glb`

The 3D engine in `three-scene.js` will automatically detect and load your custom anime character!
If this file is not present, the engine automatically displays a procedural Cursed Cyber-Villain Entity so the site always looks stunning.
